# cdk/

Aquí va **todo tu proyecto de AWS CDK**. Este folder está vacío a propósito.

Inicialízalo tú, por ejemplo:

```bash
cd cdk
cdk init app --language typescript
```

Luego define tu stack con los recursos que pide el reto: los buckets de S3, el Glue
Job, el Crawler, el Data Catalog y el workgroup de Athena. Consulta
[`../requirements.md`](../requirements.md).
